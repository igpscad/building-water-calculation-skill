# 屋面雨水排水与海绵城市计算参考

> 适用：建筑屋面雨水排水（重力流/半有压/虹吸）、郑州市暴雨强度计算、雨水调蓄与海绵城市年径流总量控制核算。
> 规范来源：CJJ 142-2014、CECS 183:2015、GB 50400-2006、DBJ41/T 256-2021、郑自然资文〔2023〕34号、郑建文〔2020〕247号、12YS6。

---

## 一、雨水量基本公式

### 1. 屋面雨水设计流量（CJJ 142-2014 第3.3.1条）

Q = k · Ψm · q · F

- Q——雨水设计流量（L/s）
- k——汇水系数；采用天沟集水且沟沿在满水时会向室内渗漏水时取 1.5，其他情况取 1.0
- Ψm——径流系数（见下表）
- q——设计暴雨强度（L/(s·hm²)）
- F——汇水面积（hm²），按水平投影面积计算

### 2. 设计暴雨强度公式（CJJ 142-2014 第3.3.4条）

q = 167 · A(1 + c·lgP) / (t + b)^n

- q——设计暴雨强度（L/(s·hm²)）
- P——设计重现期（a，年）
- t——降雨历时（min）
- A、b、c、n——当地暴雨强度公式参数（郑州取值见第二节）
- 167 为单位换算系数（mm/min → L/(s·hm²)）

### 3. 设计降雨历时（CJJ 142-2014 第3.3.6条）

t = t1 + m·t2

- t1——汇水面积汇水时间（min），按汇水面积、坡度、铺盖确定，可采用 5min
- t2——管渠内雨水流行时间（min）
- m——折减系数，取 m = 1
- 屋面雨水收集系统按屋面汇水时间计算，可取 5min

### 4. 各种汇水面径流系数（CJJ 142-2014 表3.3.2）

| 汇水面种类 | 径流系数 Ψm |
|---|---|
| 硬屋面、未铺石子的平屋面、沥青屋面 | 1.0 |
| 水面 | 1.0 |
| 混凝土和沥青地面 | 0.9 |
| 铺石子的平屋面 | 0.8 |
| 块石等铺砌地面 | 0.7 |
| 干砌砖、石及碎石地面 | 0.5 |
| 非铺砌的土地面 | 0.4 |
| 地下建筑覆土绿地（覆土厚度<500mm） | 0.4 |
| 绿地 | 0.25 |
| 地下建筑覆土绿地（覆土厚度≥500mm） | 0.25 |

> 不同汇水面平均径流系数应加权平均计算。高出汇水面有侧墙时应附加侧墙汇水面积；球形/抛物线形/斜坡较大的汇水面应附加竖向投影面积的 50%。

## 二、郑州市设计暴雨强度公式（必须用本节）

> **来源：郑自然资文〔2023〕34号《郑州市自然资源和规划局关于发布郑州市设计暴雨强度公式及设计雨型的通知》（2023年2月1日发布并启用）。该公式自发布之日起启用，郑州市 2002 版暴雨强度公式即日起废止。**

### 1. 设计暴雨强度公式（历时 t ≤ 1440min 时）

q —— 设计暴雨强度 [L/(hm²·s)]；P——设计重现期（年）；t——降雨历时（min）。

| 适用范围 | 公式 |
|---|---|
| **主城区、航空港区、中牟县、荥阳市、上街区、新郑市** | q = 2001.829(1 + 3.264·lgP) / (t + 24.8)^0.856 |
| 巩义市 | q = 2926.341(1 + 1.005·lgP) / (t + 18.3)^0.839 |
| 登封市 | q = 3632.918(1 + 0.750·lgP) / (t + 18.5)^0.850 |
| 新密市 | q = 3737.385(1 + 0.798·lgP) / (t + 18.9)^0.826 |

> 注：主城区公式分子常数 2001.829 = 167 × 11.987，与下文芝加哥法参数 A 对应。

### 2. 芝加哥法设计雨型参数取值

采用**芝加哥法**计算设计暴雨雨型。参数表：

| 地区 | A | c | b | n | r（雨峰位置系数，5~180min） |
|---|---|---|---|---|---|
| 主城区、航空港区、中牟县、荥阳市、上街区、新郑市 | 11.987 | 3.264 | 24.8 | 0.856 | 0.433 |
| 巩义市 | 17.523 | 1.005 | 18.3 | 0.839 | 0.433 |
| 登封市 | 21.754 | 0.750 | 18.5 | 0.850 | 0.433 |
| 新密市 | 22.380 | 0.798 | 18.9 | 0.826 | 0.433 |

- i——瞬时雨强（mm/min）；tb——峰前时间（min）；ta——峰后时间（min）；A、c、b、n——暴雨强度公式参数；r——雨峰位置系数。
- 芝加哥法瞬时雨强分峰前、峰后两段，按该文件公式计算（峰前 i(tb)、峰后 i(ta)）。

### 3. 1440min 设计雨型（长历时）

- 1440min 设计雨型采用 **2021 年最大降雨过程样本（即"7·20"特大暴雨）**作为典型场次进行雨量分配，再将最大 2 小时降雨量按芝加哥法重新分配。
- 1440min 降雨分配比例表：**时间间隔为 5min，共 288 个时段**；峰值出现在第 **148** 个时段（占比 **7.101%**，对应雨程 735~740min），其后依次 147 时段 5.016%、149 时段 4.619%、150 时段 3.193%。
- 完整 288 时段分配比例见该文件附表（5min 间隔），长历时调蓄/模型计算须逐时段取用。

### 4. 旧版郑州公式（已废止，仅作历史对比）

> 来源：《2014最新全国各城市暴雨强度公式目录》。**2023 年起已作废，不得再用于设计。**

- q = 7650[1 + 1.15·lg(P + P^0.143)] / (t + 37.3)^0.99（CRA 法）
- q = 3073(1 + 0.892·lgP) / (t + 15.1)^0.824（数理统计法）

## 三、雨水设计重现期

### 1. 建筑屋面雨水系统（CJJ 142-2014 表3.3.5）

| 建筑类型 | 设计重现期（a） |
|---|---|
| 采用外檐沟排水的建筑 | 1~2 |
| 一般性建筑物 | 3~5 |
| 重要公共建筑和工业厂房 | 10 |
| 窗井、地下室车库坡道 | 50 |
| 连接建筑出入口下沉地面、广场、庭院 | 10~50 |

> 注：半有压系统可取低值，虹吸式系统宜取高值。

### 2. 虹吸式屋面系统（CECS 183:2015 第3.1.2~3.1.3条）

- 一般性建筑屋面：**3~5 年**；重要公共建筑屋面和不允许渗漏的工业厂房、仓库：**宜 10 年**；大型屋面取上限值。
- **溢流口或溢流管道系统的总排水能力，不应小于设计重现期 50 年、降雨历时 5min 时的设计雨水流量（屋面径流系数取 1.0）。**

### 3. 校核要求（CJJ 142-2014 第3.1.6条）

- 总排水能力应按 **50 年或以上重现期**校核，屋面径流系数取 1.0；
- 压力流（虹吸）系统按应力计算校核，半有压系统按表3.2.4斗前水深校核。

### 3. 布置要求

- CJJ 142 第3.4.12条：一个汇水区域内雨水斗不宜少于 **2 个**，雨水立管不宜少于 **2 根**。

- 87 型雨水斗应由短管、导流罩（导流板和盖板）和压板组成；导流板不应少于 8 片，进水孔有效面积为连接管横断面积的 2~2.5 倍。
- 虹吸雨水斗应符合 CJ/T 245《虹吸雨水斗》；格栅罩间隙 6~15mm，承受外荷载不小于 0.75kN。

## 六、虹吸（压力流）式屋面雨水系统

### 1. 设计原理

按虹吸满管压力流原理设计，管道内雨水为有压流（满管流，可有适量掺气），利用雨水斗至排出管的几何高差形成负压抽吸，使水平悬吊管无需坡度即可排水。由虹吸雨水斗、连接管、悬吊管、立管、排出管、管件和固定件组成。

### 2. 与重力流的主要区别

| 项目 | 重力流 | 虹吸（压力流） |
|---|---|---|
| 流态 | 重力无压/半有压，横管非满流 | 满管压力流，悬吊管全程负压 |
| 悬吊管坡度 | 塑料管0.005、金属管0.01 | 可无坡度敷设（不得倒坡） |
| 悬吊管流速 | >0.75m/s | 不宜小于 1.0m/s |
| 立管流速 | 按表7.2.5泄流量控制 | 不宜小于 2.2m/s，且不宜大于 10m/s |
| 立管管径 | 与上游悬吊管同径或更大 | 可小于上游悬吊管管径（经计算） |
| 适用 | 一般多层、体量不大屋面 | 大型复杂屋面、大跨度厂房、天沟排水 |
| 系统最大负压 | — | 不应小于 -90kPa（管材耐负压不应小于 -80kPa） |

### 3. 关键控制参数（CJJ 142 第6.2节 / CECS 183）

- 连接管设计流速不应小于 1.0m/s；悬吊管设计流速不宜小于 1.0m/s。
- 立管设计流速不宜小于 2.2m/s，且不宜大于 10m/s。
- 过渡段（满管压力流→重力流）下游管道按重力流设计，流速不宜大于 1.8m/s，最大不应大于 3.0m/s；过渡段宜设在排出管上，长度不应小于 3.0m。
- 系统最大负压计算值不应小于 -80kPa（管材）；最不利工况复核最大负压不应小于 -90kPa。
- 最小管径不应小于 DN50（CECS 183 第3.4.14条）。
- 汇水面积大于 2500m² 的大型屋面，宜设置不少于 **2 套独立**虹吸系统。
- 天沟：坡度不宜小于 0.003；有效水深不宜小于 250mm，保护高度不小于 75mm（金属屋面且可能溢入室内时不小于 100mm）。
- 虹吸启动时间不宜大于 60s（TF = 1.2Vp/Qin,F）。
- 重力流、半有压屋面雨水不得接入虹吸系统。

## 七、雨水调蓄设施计算

### 1. 径流总雨量（CJJ 142-2014 第8.5.3条）

W = 0.06 · Ψm · q · F · t

- W——径流总雨量（m³）；q——设计暴雨强度（L/(s·hm²)）；F——汇水面积（hm²）；t——降雨历时（min）

### 2. 调蓄排放设施容积（GB 50400-2006 第9.0.4~9.0.5条）

- 调蓄排放系统降雨设计重现期宜取 **2 年**。
- 资料不足时调蓄池容积按下式估算：

V = max[ (60/1000) · (Q - Q') · tm ]

- V——调蓄池容积（m³）
- Q——雨水设计流量（L/s）
- Q'——设计排水流量（L/s），Q' = 1000W / t'
- tm——调蓄池蓄水历时（min），不大于 120min
- t'——排空时间（s），宜按 6~12h 计

### 3. 调蓄池出水管管径估算（GB 50400-2006 表9.0.6）

| 调蓄池容积（m³） | 出水管管径（mm） |
|---|---|
| 500~1000 | 200~250 |
| 1000~2000 | 200~300 |

### 4. 12YS6 雨水利用设施选用计算（河南图集）

- 雨水设计径流总量：W = 10 · ψc · hy · F（hy 设计降雨厚度 mm，重现期宜取 1~2 年；F 汇水面积 hm²）
- 水量平衡：W1（入渗）+ W2（收集回用）+ W3（弃流）= W
- 入渗设施：Ws = α·K·J·As·ts ≥ W1；As ≥ W1/(α·K·J·ts)；α 综合安全系数取 0.5~0.8；渗透时间按 24h（渗透池/渗透井按 3d）。
- 调蓄排放设施储水池调蓄容积 V3 = max[60/1000·(Q-Q')·ta]，ta≤120min，t'=6~12h（与 GB 50400 一致）。

## 八、海绵城市控制指标（河南/郑州）

### 1. 基本概念（DBJ41/T 256-2021）

- 年径流总量控制率 α：场地内累计一年得到控制的雨水量占全年总降雨量的比例。
- 设计降雨量 hy：为实现一定年径流总量控制率，用于确定设施规模的降雨量控制值（mm）。

### 2. 下垫面径流系数（DBJ41/T 256-2021 表4.1.3）

| 汇水面种类 | 雨量径流系数 | 流量径流系数 |
|---|---|---|
| 绿化屋面（基土层厚度≥300mm） | 0.30~0.40 | 0.40 |
| 硬屋面、未铺石子的平屋面、沥青屋面 | 0.80~0.90 | 0.85~0.95 |
| 铺石子的平屋面 | 0.60~0.70 | 0.80 |
| 混凝土或沥青路面及广场 | 0.80~0.90 | 0.85~0.95 |
| 大块石等铺砌路面及广场 | 0.50~0.60 | 0.55~0.65 |
| 级配碎石路面及广场 | 0.40 | 0.40~0.50 |
| 干砌砖石或碎石路面及广场 | 0.40 | 0.35~0.40 |
| 非铺砌的土路面 | 0.30 | 0.25~0.35 |
| 绿地 | 0.15 | 0.10~0.20 |
| 水面 | 1.00 | 1.00 |
| 地下建筑覆土绿地（覆土≥500mm） | 0.15 | 0.25 |
| 地下建筑覆土绿地（覆土<500mm） | 0.30~0.40 | 0.40 |
| 透水铺装地面 | 0.08~0.45 | 0.08~0.45 |
| 下沉广场（50年及以上一遇） | — | 0.85~1.00 |

- 综合径流系数：ψz = Σ(Fi·ψi) / F（各下垫面加权平均）。
- 无设施控制的不透水下垫面，年径流总量控制率取 0；α = (1 - ψz)×100%。

### 3. 水量计算（DBJ41/T 256-2021）

- 雨水径流总量：W = 10 · ψzc · hy · F（m³）
- 雨水设计流量：Q = q · ψzm · F（L/s）
- 初期弃流量：Wi = 10 · δ · F（m³）；初期径流厚度 δ——一般屋面 1~3mm，小区路面 2~5mm，市政路面 7~15mm。

### 4. 郑州市设计降雨量对应表（DBJ41/T 256-2021 表B.2）

| 年径流总量控制率 | 60% | 65% | 70% | 75% | 80% | 85% | 90% |
|---|---|---|---|---|---|---|---|
| 郑州设计降雨量（mm） | 10.5 | 12.2 | 14.1 | 16.6 | 20.0 | 24.3 | 30.8 |

> 数据来源：国家气象局气候中心数据中心（1986~2016 年）。具体项目控制率以规划条件/项目批复为准（郑州执行《郑州市海绵城市规划设计导则（试行）》郑政办文〔2016〕50号）。

### 5. 郑州施工图审查要点（郑建文〔2020〕247号）

- 年径流总量控制率核算：核查径流系数选取、下垫面与图纸一致、分区调蓄容积与总调蓄容积正确、滞蓄净化容积与汇水面积匹配。
- 屋面雨水收集系统应**独立设置**，严禁与建筑生活污水、废水排水连接，严禁在室内设置敞开式检查口或检查井（GB 50400 强条）。
- 项目应有海绵城市专项设计，与主体工程同时设计、同时施工、同时投入使用。

## 九、计算易错点

1. **郑州公式必须用 2023 版**：主城区用 q = 2001.829(1+3.264lgP)/(t+24.8)^0.856，单位 L/(hm²·s)（不是 L/(s·ha) 以外的其他系数）；旧 3073/7650 公式已废止。区分主城区、巩义、登封、新密不同参数，切勿套错地区。
2. **单位换算**：q 的单位是 L/(s·hm²)，F 用 hm²；公式 q=167A(1+clgP)/(t+b)^n 中 A 为 mm/min 体系参数（主城区 A=11.987），与直接算 L/(hm²·s) 的分子常数 2001.829 差 167 倍，不要混用。
3. **重现期双轨**：设计重现期（一般 3~5 年）用于选系统管径；**50 年校核重现期**用于溢流口/溢流管道总排水能力核算，径流系数取 1.0，二者不能混为一谈。
4. **径流系数取值**：屋面排水设计 Ψm 取 1.0（硬屋面）；海绵核算时雨量径流系数才用 0.80~0.90，不要把海绵用的折减系数直接套到雨水管渠设计上。
5. **重力流立管**：按表7.2.5 选泄流量时区分铸铁管、钢管、塑料管及不同壁厚，塑料管 DN100 有 90×3.2（7.40）和 110×3.2（12.80）两档，不能只看公称直径。
6. **虹吸≠重力**：虹吸悬吊管可无坡度、立管可缩径，但流速/负压有严格区间（立管 2.2~10m/s、负压≥-90kPa）；重力流横管必须有坡、充满度≤0.8。
7. **雨水斗不少于 2 个、立管不少于 2 根**；虹吸两斗间距≤20m。
8. **设计雨型**：短历时（5~180min）用芝加哥法 r=0.433；长历时调蓄模型用 1440min"7·20"分配表（5min 间隔 288 时段），不要用 r=0.433 去套 24h 雨型。
9. **调蓄池**：重现期取 2 年、排空时间 6~12h、蓄水历时 tm≤120min；出水管管径按表9.0.6 估算。
10. **海绵年径流总量控制率**：郑州 75% 对应设计降雨量 16.6mm；不透水下垫面控制率为 0，不能用单一 ψz 直接推算全场控制率，须分下垫面加权。
