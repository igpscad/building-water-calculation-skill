> 来源：CJJ 232-2016《建筑同层排水工程技术规程》、《建筑特殊单立管排水系统设计手册》（姜文源等，中国建筑工业出版社，2016）、CECS 271:2013《旋流加强(CHT)型特殊单立管排水系统技术规程》、GB/T 24603-2016《箱式叠压给水设备》、CJJ 140-2010《二次供水工程技术规程》、CECS 109:2013《建筑给水减压阀应用技术规程》、吉博力同层排水介绍。

## 一、同层排水

### 1.1 定义与基本要求

- **同层排水**：排水支管不穿越本层楼板，在同一楼层内与排水立管连接的排水方式（对应传统"异层/隔层排水"中支管穿到下层吊顶连接）。
- 敷设方式分两类（CJJ 232 第3.2节）：
  - **沿墙敷设**：墙排式卫生器具 + 假墙/非承重墙内暗装管道，挂壁式坐便器配隐蔽式冲洗水箱。
  - **地面敷设（降板）**：局部降板或整体降板后，管道埋设于降板填层或架空层内。
  - 两种方式可结合使用。
- **水封**：器具排水管水封深度不得小于 50mm；不得采用活动机械密封替代水封（第3.1.9条）。
- **存水弯接管**：存水弯接管管径不应小于卫生器具排水管管径；卫生器具与存水弯之间管道长度宜 ≤ 800mm；同一管段上不得重复设置水封（第3.1.10条）。

### 1.2 降板（地面敷设）构造

- 降板区域应采用现浇钢筋混凝土楼板，厚度经结构专业计算确定（第3.3.8条）。
- **降板高度（结构楼板至建筑面层净空高度）无统一固定值**，应根据卫生器具型式及布置、降板区域、管径大小、管道长度、接管要求、管材种类综合确定；采用排水汇集器时还应按产品要求确定（第3.3.9条）。设计时不得直接套用经验数值。
- 降板空间采用填充方式时应填充轻质材料，管道两侧对称分层填充，不得机械填充（第3.3.13条）。
- 降板区域应设防水层（结构板面和完成地面均设）；设积水排除措施时，积水排除装置接入立管前应设水封，并具防干涸、防返溢功能（第3.3.13、3.4.5条）。
- 采用排水汇集器时，排出管管径经水力计算确定且不应小于接入汇集器的最大横管管径，并应设清扫口或便于清扫疏通的装置（第3.3.11条）。

### 1.3 管道布置与连接（CJJ 232 第3.4节）

| 项目 | 要求 | 条文 |

| 管道敷设位置 | 宜在管道井（管窿）、装饰墙、降板填层或架空楼板内暗设 | 3.4.1 |
| 横支管接入 | 器具排水管与横支管连接宜采用 45° 斜三通/弯头斜向接入 | 3.4.5 |
| 横管水平连接 | 采用 45° 斜三通；上下游横管水平面倾斜角不宜小于 15° | 3.4.6 |

### 1.5 同层排水 vs 异层（传统）排水优缺点

| 对比项 | 同层排水 | 传统异层（隔层）排水 |
|---|---|---|
| 支管穿楼板 | 不穿本层楼板，漏水不殃及下层 | 穿楼板接下层，漏水易到楼下 |
| 卫生间布局 | 坐便可移位，假墙隐藏管道，布局灵活 | 坐便器坑位受立管位置固定 |
| 排水噪声 | 支管不穿楼板 + HDPE/假墙隔声，噪声低 | 上层冲水噪声传至下层吊顶 |
| 卫生死角 | 挂墙坐便器离地，地面无死角 | 落地坐便器下方难清洁 |
| 层高/造价 | 降板占建筑净高，造价较高；沿墙式不降板但需假墙 | 无降板，造价低 |
| 检修 | 同层检修（地漏/清扫口在本层）；降板式检修受填层影响 | 下层吊顶内检修，影响下层用户 |

> 来源：吉博力《同层排水介绍》对比图与 CJJ 232 条文。

## 二、特殊单立管排水系统

### 2.1 定义与分类

- **特殊单立管**：在普通单根排水立管基础上，通过上部特殊管件（加强型旋流器/苏维托）、下部特殊管件（大曲率异径弯头/泄压管）或采用内螺旋管材，改善立管水气流动状态、提高通水能力而不另设专用通气立管的系统。
- 按特殊部位分三类（《设计手册》第3.2节）：
  1. **管件特殊单立管**：上部+下部特殊管件，普通光壁管材（如苏维托、加强型旋流器）。
  2. **管材特殊单立管**：采用内螺旋/螺旋消音管材。
  3. **管件与管材均特殊**：特殊管件 + 内螺旋管材（如 CHT、AD 型）。

### 2.2 适用范围（《设计手册》第3.1节）

特殊单立管宜在下列情况采用：
1. 排水立管设计排水流量大于普通单立管（伸顶通气）最大排水能力；
2. 建筑标准要求较高、需降低排水噪声的高层/多层住宅，**特别适用于居住类建筑小卫生间**；
3. 同层接入立管的横支管数较多；
4. 卫生间/管道井面积小，难以设置专用通气立管；
5. 需设环形/器具通气管但不设通气立管。

> 注意：DN100(dn110) 特殊单立管**仅适用于每层横支管管径 ≤ DN100(dn110)、或每层横支管设计排水流量 ≤ 2.5 L/s 的场所**；不适用于公共建筑多厕位卫生间。

### 2.4 CHT 型系统配置（CECS 271:2013 /《设计手册》表6.3.1）

- 上部特制配件：CB4N(P) 型（PVC-U）或 CB4N(F) 型（PVC-U 外覆防火材料）加强型旋流器。
- 立管管材：PVC-U 加强型内螺旋管；湖南大学实测系统最大排水能力 8.0 L/s。
- 下部特制配件：
  - LL 型底部异径弯头 LL-100×150——≤18 层采用；
  - LLS 型大曲率底部异径弯头 LLS-100×150——>18 层采用。
- 立管底部不另设稳流接头。

### 2.5 管道设置通用要求（《设计手册》第3.4节）

- 排水立管宜靠近排水量最大的卫生器具（坐便/蹲便）；住宅厨房与卫生间排水立管宜分别设置。
- 立管不得穿越卧室、客厅、餐厅、病房等安静房间。
- 塑料排水立管表面受热温度可能 >60℃ 时应隔热；与家用灶具边缘净距不小于 0.4m。
- 多根立管汇合横干管管径不得小于 DN150；立管接横干管宜在管顶或两侧 45° 范围内用 45° 斜三通接入。
- 最低横支管与立管连接处至立管管底最小垂直距离按手册表3.4.1（不满足时底层单独排出或横支管接横干管，接入点距立管下游水平距离不小于 1.5m）。

## 三、叠压（无负压）供水

### 3.1 定义与原理（CJJ 140-2010 第2.0.3条）

- **叠压供水**：利用城镇供水管网压力直接增压的二次供水方式。设备串接在市政管网上串压，在市政余压基础上叠加水泵扬程，水泵进水侧为密闭承压（非敞口水池），故又称"无负压"。
- **箱式叠压给水设备**（GB/T 24603-2016 第3.1条）：带常压水箱及增压装置、水泵机组和控制系统，具有流量调节的叠压给水设备。增压装置按设备额定供水量将常压水箱储水增压到限定压力值（限定值为当地供水部门规定的压力值）。

### 3.2 分类与型号（GB/T 24603-2016）

- 按安装和结构型式：室内整体式(NZ)、室内分体式(NF)、室外整体式(WZ)。
- 型号组成：`XDY - 型式 - 水箱总容积(m³) - 额定供水流量(m³/h) - 额定供水压力(MPa) - 水泵台数(含备用泵)`。
- 标记示例：额定供水流量 40 m³/h、水箱 30 m³、额定压力 0.45 MPa、工作泵 2 台+备用 1 台的室内整体式 → **XDY-NZ-30-40-0.45-3**。
- 环境温度：4℃~40℃。

### 3.3 适用与限制（CJJ 140-2010）

- **应有条件使用**：采用叠压供水时，不得造成该地区城镇供水管网水压低于本地规定的最低供水服务压力（第5.2.4条）。
- 设计压力应考虑城镇供水管网可利用水压（第5.3.3条）。
- 叠压供水设备进水管处应设过滤器（滤网 20~40 目）（第6.4.14条）。
- 叠压供水设备应预留消毒设施接口（第5.4.7条）。
- 采用叠压供水的用户变更用水性质时，应经供水企业同意（第11.1.6条）。
- 不适用/慎用场合（工程惯例，依据 CJJ 140 对市政水压的保护原则）：市政管网压力不足或波动大、供水部门不允许串接、用水量大且无调节能力、对水质安全要求高且需完全独立储水的场所；此类宜改用"水池+变频"方式。

### 3.4 叠压 vs 传统变频（水池+变频）

| 对比项 | 叠压（无负压） | 水池（箱）+变频 |
|---|---|---|
| 与市政关系 | 密闭串接，利用市政余压 | 敞口水池隔断，市政余压被释放 |
| 节能 | 叠加余压，水泵扬程小，较节能 | 全扬程提升，能耗略高 |
| 水质 | 密闭不接触空气，二次污染风险低 | 敞口水箱易受污染，需消毒、定期清洗 |
| 调蓄能力 | 差（箱式有小调节，纯无负压几乎无） | 有水池调蓄，断水时可短时供水 |
| 对市政影响 | 可能抽吸市政管网，需核定 | 不影响市政管网压力 |
| 水质防护要求 | 预留消毒接口、倒流防止 | 必须设消毒设备、人孔带锁、空气隔断 |

## 四、二次供水

### 4.1 供水方式分类（CJJ 140-2010 第5.2.2条）

二次供水系统可采用下列方式：
1. 增压设备和高位水池（箱）联合供水；
2. 变频调速供水；
3. 叠压供水；
4. 气压供水。

> 设计用水量应计入管网漏失和未预见水量，之和按最高日用水量的 **8%~12%** 计（第5.3.1条）。竖向分区按 GB 50015 执行。

### 4.2 水池（箱）设置要求（CJJ 140 第6.1节）

| 项目 | 要求 | 条文 |
|---|---|---|
| 独立设置 | 宜独立设置，内壁光洁、内拉筋无毛刺、不渗漏 | 6.1.2 |
| 分格 | 容积 >50m³ 时宜分两格，能独立工作 | 6.1.5 |
| 高度 | 水池高度 ≤3.5m，水箱 ≤3m；>1.5m 时内外设爬梯 | 6.1.6 |
| 布置净距 | 侧壁距墙 ≥0.7m（有管道侧 ≥1.0m）；顶距楼板 ≥0.8m；底架空距地 ≥0.5m | 6.1.7 |
| 出水管 | 出水管管底高于箱内底 ≥0.1m | 6.1.8-2 |
| 溢流管 | 管径大于进水管；出口设防腐蚀网，与排水系统不直接连接，空气间隙 ≥0.2m | 6.1.8-5 |
| 泄水管 | 设在底部，管径 ≥DN50；空气间隙 ≥0.2m | 6.1.8-6 |
| 通气管 | 管径 ≥DN25，管口防护 | 6.1.8-7 |
| 人孔 | 加盖带锁，高出箱顶 ≥0.1m；圆人孔直径 ≥0.7m，方人孔每边 ≥0.6m | 6.1.8-8 |
| 消毒 | 水池（箱）应设消毒设备（臭氧/紫外线/水箱自洁） | 6.5.1 |

### 4.3 水泵选型（CJJ 140 第6.3节）

- 选用低噪声、节能、维修方便的水泵；居住建筑噪声/振动应达 JB/T 8098、JB/T 8097 的 **B 级**，公共建筑 **C 级**。
- 变频控制时，水泵额定转速工作点应位于水泵高效区**末端**。
- 用水量变化大时宜多台泵组合；应设备用泵，备用泵供水能力不小于最大一台运行泵。
- 每台泵出水管装压力表、止回阀、阀门，必要时设水锤消除；宜独立吸水管；自灌式吸水。
- 电机额定功率 ≤11kW 宜用成套水泵机组，机组减振。

### 4.4 水质防护（CJJ 140）

- 二次供水水质应符合 GB 5749《生活饮用水卫生标准》（第4.0.1条）。
- 涉水产品应符合《生活饮用水输配水设备及防护材料安全性评价标准》GB/T 17219。
- 水池（箱）每半年清洗消毒不少于一次，同时检测水质；检测项目至少含色度、浊度、嗅味、肉眼可见物、pH、大肠杆菌、细菌总数、余氯（第11.3.6、11.3.7条）。
- 严禁二次供水管道与非饮用水管道连接（第6.4.4条）；管道标识宜为蓝色。
- 倒流防止器宜选低阻力型；减压阀/水位控制阀/叠压设备进水管前设 20~40 目过滤器。

## 五、减压阀（CECS 109:2013）

### 5.1 类型

- **比例式减压阀**：阀后压力与阀前压力成固定比，阀前压力稳定时用。
- **可调式减压阀**：阀后压力可调，分直接作用式、先导式；DN≥50 时宜选先导式。
- **差压式减压阀**：维持阀前后差压恒定。
- **双级减压阀**：减压比大时串联使用。

### 5.2 减压比定义

- 减压比 **B = P1/P2**（P1 进口压力，P2 出口压力，均为 MPa）。
- 动压比 Bd = P1/P2（有流量通过时）；静压比 Bj（密封无流量时）。
- 比例式减压阀出口压力计算：
  - 给动压比：**P2 = P1 / Bd**（式3.2.5-1）
  - 给静压比：**P2 = K·P1 / Bj**，K 为动压折减系数 0.70~0.90（式3.2.5-2）

### 5.3 减压比限值（CECS 109 第3.3节、表3.2.2）

| 系统 | 减压比 B 限值 | 备注 |
|---|---|---|
| 生活给水（一般） | 不宜大于 **3:1** | 超过时气蚀校核/串联减压 |
| 生活给水安静区域 | 不宜大于 **2.5:1** | |
| 生活热水 | 不宜大于 **2.5:1** | 超过按图3.3.3校核 |
| 消防给水 | 不宜大于 **4:1** | 可不行气蚀校核；超过 4:1 宜串联或选可调式 |
| 双级减压阀 | 3.5:1 ~ 8:1 | |

### 5.4 选型与安装要点

- 减压阀公称压力 PN 应大于设置场所管道最大工作压力；公称尺寸 DN 宜与出水管道相同。
- 介质温度 >45℃ 且 ≤80℃ 时选热水型减压阀；阀件材质耐腐蚀性应优于连接管道。
- 串联减压：前一级可选比例式，后一级选可调式。
- 阀组安装前上游管道应冲洗干净；安装方向与水流一致，阀瓣垂直运动；阀前设过滤器。
- 同径并联：单台流量按设计流量 100%，两台出口压力一致同时工作。
- 高层建筑减压阀供水系统，阀后配水件最大压力应按减压阀失效工况校核，不大于配水件产品标准水压试验压力（CJJ 140 第5.3.4条）。
