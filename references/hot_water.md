- 当无水温资料时按表6.2.5采用；河南图集12YS3取值同此（河南北部地面水4℃、南部5℃；地下水北部10~15℃、南部15~20℃）。

### 2. 水加热设备出水温度（第6.2.6条）

- 冷水总硬度（以CaCO₃计）<120mg/L时，最高出水温度≤70℃；≥120mg/L时≤60℃。
- 系统不设灭菌消毒设施时：医院、疗养所60~65℃，其他建筑55~60℃；设灭菌消毒设施时均宜相应降低5℃。
- 配水点水温不应低于45℃。
- 来源：GB 50015-2019 第6.2.6条。

## 三、设计小时耗热量计算

### 1. 全日集中热水供应系统（式6.4.1-1）

适用于宿舍（居室内设卫生间）、住宅、别墅、酒店式公寓、招待所、培训中心、旅馆、宾馆客房（不含员工）、医院住院部、养老院、幼儿园、托儿所（有住宿）、办公楼等。

```
Qh = Kh · m·qr·C·(tr − tl)·ρr / T · Cγ        (6.4.1-1)
```

| 符号 | 含义 | 取值 |
|---|---|---|
| Qh | 设计小时耗热量(kJ/h) | — |
| m | 用水计算单位数（人数或床位数） | — |
| qr | 热水用水定额[L/(人·d)或L/(床·d)] | 取表6.2.1-1最高日 |
| tr | 热水温度(℃) | tr=60 |
| C | 水的比热[kJ/(kg·℃)] | C=4.187 |
| tl | 冷水温度(℃) | 取表6.2.5 |
| ρr | 热水密度(kg/L) | 60℃约0.983 |
| T | 每日使用时间(h) | 取表6.2.1-1 |
| Cγ | 热水供应系统热损失系数 | 1.10~1.15 |
| Kh | 小时变化系数 | 取表6.4.1 |

- 来源：GB 50015-2019 式(6.4.1-1)。

### 2. 热水小时变化系数 Kh（表6.4.1，节选）

| 类别 | 热水定额[L/(人或床·d)] | 使用人(床)数 | Kh |
|---|---|---|---|
| 住宅 | 60~100 | 100~6000 | 4.8~2.75 |
| 别墅 | 70~110 | 100~6000 | 4.21~2.47 |
| 酒店式公寓 | 80~100 | 150~1200 | 4.00~2.58 |
| 宿舍(居室内设卫生间) | 70~100 | 150~1200 | 4.80~3.20 |
| 招待所/培训中心/普通旅馆 | 25~100 | 150~1200 | 3.84~3.00 |
| 宾馆 | 120~160 | 150~1200 | 3.33~2.60 |
| 医院、疗养院 | 60~200 | 50~1000 | 3.63~2.56 |
| 幼儿园、托儿所 | 20~40 | 50~1000 | 4.80~3.20 |
| 养老院 | 50~70 | 50~1000 | 3.20~2.74 |

- Kh取值规则：定额高、使用人(床)数多取低值，反之取高值；处于上下限之间时，用"定额×人数"乘积作内插变量。表中未列入的办公楼、公共浴室等，可按给水的小时变化系数选值。
- 内插示例（医院800床、110L/(床·d)）：Kh = 3.63 − [(800×110−50×70)/(1000×130−50×70)]×(3.63−2.56) ≈ 2.92。
- 来源：GB 50015-2019 表6.4.1；《集中热水供应系统设计探讨（一）》slide8。

### 3. 定时集中/局部热水供应系统（式6.4.1-2）

适用于定时集中、工业企业生活间、公共浴室、宿舍（公用盥洗）、剧院化妆间、体育场(馆)运动员休息室等。

```
Qh = Σ qh·C·(tr1 − tl)·ρr·no·bg·Cγ          (6.4.1-2)
```

| 符号 | 含义 |
|---|---|
| qh | 卫生器具热水小时用水定额(L/h)，取表6.2.1-2 |
| tr1 | 使用温度(℃)，取表6.2.1-2"使用水温" |
| no | 同类型卫生器具数 |
| bg | 同类型卫生器具同时使用百分数 |

- bg取值：住宅、旅馆、医院、疗养院病房卫生间内浴盆或淋浴器按70%~100%计，其他器具不计（定时连续供水时间应≥2h）；工业企业生活间、公共浴室、宿舍(公用盥洗)、剧院、体育场(馆)浴室内的淋浴器和洗脸盆按给水设计秒流量表上限取值；住宅一户多卫生间可按一个卫生间计。
- 来源：GB 50015-2019 式(6.4.1-2)。

### 4. 设计小时热水量（式6.4.2）

```
qrh = Qh / [(tr2 − tl)·C·ρr·Cγ]             (6.4.2)
```

- qrh：设计小时热水量(L/h)；tr2：设计热水温度(℃)。
- 即：设计小时热水量 = 设计小时耗热量 ÷ 温升（热水与冷水的温差，含热损失系数）。
- 来源：GB 50015-2019 式(6.4.2)。

## 四、加热设备选型与计算

### 1. 各类水加热器特点与适用条件

| 类型 | 特点 | 适用条件 |
|---|---|---|
| 导流型容积式 | 带导流装置，换热储热一体、储热量大，供水温度稳定，对热媒变化适应强；存在少量冷/温水区 | 热源不能满足设计小时耗热量；用水量变化大、供水可靠性要求高；设备用房宽裕 |
| 半容积式 | 换热、储热分开，有一定储热量，供水温度较稳定，无冷/温水区，占地较小 | 热源能满足设计小时耗热量；水温水压要求平稳；机房面积小；设有机械循环的系统 |
| 半即热式 | 换热储热一体、储热量很小，需配随流量/压力自动调节热媒装置（出水温度稳定在设定±3℃），无冷/温水区 | 热源能满足设计秒流量所需耗热量；蒸汽热媒最低工作压力≥0.15MPa且供汽压力稳定；用水较均匀 |
| 快速式 | 热媒与被加热水快速流动、储热量很小，无储存调节容积，生活热水需配储热水箱联合使用 | 太阳能、热泵为热源的循环加热；耗热量稳定的游泳池池水加热；无凝结水回收的中小型系统 |

- 来源：《集中热水供应系统设计探讨（一）》slide17。

### 2. 加热设备设计小时供热量

- **导流型容积式/燃油(气)热水机组（式6.4.3-1）**

```
Qg = Qh − η·Vr·(tr2 − tl)·C·ρr / T1        (6.4.3-1)
```

| 符号 | 含义 / 取值 |
|---|---|
| Qg | 设计小时供热量(kJ/h) |
| η | 有效贮热容积系数：导流型容积式0.8~0.9；第一循环自然循环时卧式贮热水罐0.80~0.85、立式0.85~0.90；第一循环机械循环时卧/立式均取1.0 |
| Vr | 总贮热容积(L) |
| T1 | 设计小时耗热量持续时间：全日集中取2~4h；定时集中取定时供水时间 |

- 当Qg计算值小于平均小时耗热量时，Qg应取平均小时耗热量。
- **半容积式**：设计小时供热量按设计小时耗热量计算，即 Qg=Qh。
- **半即热式、快速式（式6.4.3-2）**

```
Qg = 3600·qg·(ty − tl)·C·ρy               (6.4.3-2)
```

- qg：系统供水总干管设计秒流量(L/s)。
- 来源：GB 50015-2019 第6.4.3条。

### 3. 水加热器加热面积（式6.5.7）

```
Fjr = Qg / (ε·K·Δtj)                       (6.5.7)
```

| 符号 | 含义 / 取值 |
|---|---|
| Fjr | 加热面积(m²) |
| Qg | 设计小时供热量(kJ/h) |
| K | 传热系数[kJ/(m²·℃·h)]，按产品实测 |
| ε | 水垢及热媒分布不均匀影响系数 | 0.6~0.8 |
| Δtj | 热媒与被加热水计算温度差(℃)，按6.5.8 |

### 4. 计算温度差 Δtj（式6.5.8）

- **导流型容积式、半容积式（算术平均温差）**

```
Δtj = (tmc + tmz)/2 − (tc + tz)/2          (6.5.8-1)
```

- tmc、tmz：热媒初温、终温(℃)；tc、tz：被加热水初温、终温(℃)。

- **快速式、半即热式（对数平均温差）**

```
Δtj = (Δtmax − Δtmin) / ln(Δtmax/Δtmin)   (6.5.8-2)
```

### 5. 热媒计算温度（第6.5.9条）

- 热媒为饱和蒸汽：压力>70kPa时tmc按饱和蒸汽温度计算；≤70kPa时tmc按100℃计算；热媒终温tmz由产品提供，可按50~90℃。
- 热媒为热水：初温按热媒供水最低温度；当tmc=70~100℃时，终温可按tmz=50~80℃。
- 来源：GB 50015-2019 第6.5.7~6.5.9条。

### 6. 水加热设施贮热量（表6.5.11）

| 加热设施 | 蒸汽或≥95℃热水为热媒·工业淋浴室 | 同上·其他建筑 | ≤95℃热水为热媒·工业淋浴室 | 同上·其他建筑 |
|---|---|---|---|---|
| 内置加热盘管的加热水箱 | ≥30min·Qh | ≥45min·Qh | ≥60min·Qh | ≥90min·Qh |
| 导流型容积式水加热器 | ≥20min·Qh | ≥30min·Qh | ≥30min·Qh | ≥40min·Qh |
| 半容积式水加热器 | ≥15min·Qh | ≥15min·Qh | ≥15min·Qh | ≥20min·Qh |

- Qh为设计小时耗热量(kJ/h)。半即热式、快速式当热媒按设计秒流量供应且有完善可靠的温控及安全装置时，可不设贮热水罐。
- 来源：GB 50015-2019 表6.5.11。

### 7. 台数与检修（第6.5.3、6.5.4条）

- 医院集中热水系统热源机组及水加热设备不得少于2台；其他建筑水加热设备不宜少于2台。当一台检修时，其余各台总供热能力不得小于设计小时供热量的60%。
- 医院建筑应采用无冷温水滞水区的水加热设备。
- 来源：GB 50015-2019 第6.5.3、6.5.4条。

### 8. RV系列导流型容积式水加热器主要参数（01S122-1）

| 工况 | 参数 | RV-03（卧式） | RV-04（立式） |
|---|---|---|---|
| 汽-水换热 | 饱和蒸汽压力Pt(MPa) | 0.2~0.4 | 0.2~0.4 |

| | 传热系数K[W/(m²·℃)] | 800~1000 | 900~1100 |

## 五、循环流量与管道热损失

### 1. 全日集中热水供应循环流量（式6.7.5）

```
qx = Qs / (C·ρr·Δts)                       (6.7.5)
```

| 符号 | 取值 |
|---|---|
| qx | 全日集中热水循环流量(L/h) |
| Qs | 配水管道热损失(kJ/h)：单体建筑取(2%~4%)Qh，小区取(3%~5%)Qh |
| Δts | 配水管道热水温差(℃)：单体建筑取5~10，小区取6~12 |

- 经验控制值：qx ≈ (0.1~0.15)qrh。
- 来源：GB 50015-2019 式(6.7.5)；《集中热水供应系统设计探讨（一）》slide53。

### 2. 定时集中热水循环流量（第6.7.6条）

- 定时集中系统循环流量可按循环管网总水容积的2~4倍计算（含配水管、回水管，不含不循环管网、水加热器或贮热设施容积）。

### 3. 热水管道流速（表6.7.8）

| 公称直径DN(mm) | 15~20 | 25~40 | ≥50 |
|---|---|---|---|
| 流速(m/s) | ≤0.8 | ≤1.0 | ≤1.2 |

- 锅炉或水加热器出水温度与配水点最低水温之差：单体建筑≤10℃，小区≤12℃（第6.7.7条）。
- 来源：GB 50015-2019 表6.7.8。

### 4. 循环水泵（第6.7.10条）

```
qxh = Kx · qx                              (6.7.10-1)
Hb  = hp + hx                              (6.7.10-2)
```

- qxh：循环水泵流量(L/h)；Kx：循环措施附加系数，取1.5~2.5。
- Hb：循环水泵扬程(kPa)；hp：循环流量通过配水管网水头损失；hx：通过回水管网水头损失。采用半即热/快速水加热器时尚应计入水加热器水头损失；Hb较小时可选0.05~0.10MPa。
- 循环泵应选热水泵，宜设备用泵交替运行；泵前回水总管设温度传感器控制开停。
- 工程经验qxh（按qrh比值）：温控循环阀/流量平衡阀作循环元件时qxh=0.15qrh；同程系统或设导流三通的异程系统qxh=(0.20~0.25)qrh；大阻力短管异程系统qxh≥0.3qrh。
- 来源：GB 50015-2019 第6.7.10条；《集中热水供应系统设计探讨（一）》slide54。

## 六、太阳能热水系统

### 1. 平均日耗热量（式6.6.3）

```
Qmd = qmr·m·b1·C·ρr·(tr − tLm)            (6.6.3)
```

| 符号 | 含义 / 取值 |
|---|---|
| Qmd | 平均日耗热量(kJ/d) |
| qmr | 平均日热水用水定额[L/(人·d)]，取表6.2.1-1平均日 |
| m | 用水计算单位数 |
| b1 | 同日使用率（住宅为入住率），见表6.6.3-1 |
| tLm | 年平均冷水温度(℃)，按当地自来水厂年平均水温 |

**同日使用率 b1（表6.6.3-1）**

| 建筑 | 住宅 | 宾馆旅馆 | 宿舍 | 医院疗养院 | 幼儿园/托儿所/养老院 |
|---|---|---|---|---|---|
| b1 | 0.5~0.9 | 0.3~0.7 | 0.7~1.0 | 0.8~1.0 | 0.8~1.0 |

- 分散供热、分散集热系统b1=1。

**太阳能保证率 f（表6.6.3-2）**

|---|---|---|---|---|

- 宿舍、医院、疗养院、幼儿园、托儿所、养老院等负荷稳定建筑取上限，其他取下限。

### 2. 集热器总面积

- **直接太阳能热水系统（式6.6.2-1）**

```
Ajz = Qmd·f / [bj·Jt·ηj·(1 − ηl)]         (6.6.2-1)
```

| 符号 | 含义 / 取值 |
|---|---|
| Ajz | 直接系统集热器总面积(m²) |
| Qmd | 平均日耗热量(kJ/d) |
| f | 太阳能保证率 |
| bj | 集热器面积补偿系数：朝南偏离角≤15°、倾角当地纬度±10°时取1，否则按GB50364补偿 |
| Jt | 集热器总面积平均日太阳辐照量[kJ/(m²·d)]，按GB50015附录H/GB50364附录A |
| ηj | 年平均集热效率：分散集热分散供热40%~70%；集中集热30%~45% |
| ηl | 集热系统热损失：集热器紧靠集热水箱15%~20%；与水箱分两处布置20%~30% |

- **间接太阳能热水系统（式6.6.2-2）**

```
Ajj = Ajz·(1 + UL·Ajz / (K·Fjr))          (6.6.2-2)
```

- UL：集热器热损失系数，平板型14.4~21.6、真空管型3.6~7.2 [kJ/(m²·℃·h)]；K：水加热器传热系数；Fjr：水加热器加热面积。
- GB50364同一公式表达：Ac = Qw·ρw·Cw·(tend−to)·f / [JT·ηcd·(1−ηL)]，Qw=qr·m·b1，ηL宜取0.20~0.30。
- 来源：GB 50015-2019 式(6.6.2-1、6.6.2-2)；GB 50364-2018 式(5.4.2-1)。

### 3. 集热水箱（罐）有效容积（式6.6.5-1）

```
Vrx = qrjd · Aj                            (6.6.5-1)
```

- Vrx：集热水加热器或集热水箱有效容积(L)；Aj=Ajz或Ajj。
- qrjd：集热器单位轮廓面积平均日产60℃热水量[L/(m²·d)]，无条件时：直接系统40~80、间接系统30~55。
- 集中集热、集中供热系统集热水箱宜与供热水箱分开串联，供热侧有效容积按表6.5.11确定。
- 来源：GB 50015-2019 第6.6.5条。

### 4. 集热循环泵流量（式6.6.5-3）

```
qx = qgz · Aj                              (6.6.5-3)
```

- qx：集热系统循环流量(L/s)；qgz：单位轮廓面积集热器工质流量[L/(m²·s)]，无条件取0.015~0.020。
- 来源：GB 50015-2019 第6.6.5条。

### 5. 辅助热源（第6.6.6条）

- 辅助热源供热量按无太阳能时参照第6.4.3条计算；控制应在充分利用太阳能集热量前提下，按供水方式采用手动、全日自动或定时自动控制。
- 来源：GB 50015-2019 第6.6.6条。

### 6. 热泵热水供应（第6.6.7条）

- **水源热泵设计小时供热量（式6.6.7-1）**

```
Qg = m·qr·C·(tr − tl)·ρr·Cγ / T5          (6.6.7-1)
```

- T5：热泵机组设计工作时间(h/d)，取8~16。

- **贮热水箱有效容积（式6.6.7-2）**

```
Vr = k1·(Qh − Qg)·T1 / [(tr − tl)·C·ρr]  (6.6.7-2)
```

- k1：用水均匀性安全系数，取1.25~1.50。快速水加热器：板式K=3000~4000、管束式K=1500~3000[kJ/(m²·℃·h)]，Δtj取3~6℃。
- **空气源热泵适用条件（第6.6.7条第5款）**：最冷月平均气温≥10℃地区可不设辅助热源；<10℃且≥0℃宜设辅助热源或延长工作时间；<0℃不宜采用空气源热泵。
- 来源：GB 50015-2019 第6.6.7条。

## 七、管材、保温与敷设

- 管材：热水管宜选薄壁不锈钢管、薄壁铜管、塑料热水管、复合热水管等；采用塑料(或塑料与金属复合)热水管时，设备机房内管道不应采用塑料热水管（第6.8.2条）。
- 热水横管坡度：上行下给式不宜小于0.005，下行上给式不宜小于0.003（第6.8.12条）。12YS3要求横管有不小于3‰坡度，供水同向流、回水逆向流以利放气泄水。
- 保温：水加热设备、贮水器、热水箱、供回水干管立管、机械循环回水管均应保温，厚度经计算确定（第6.8.14条）。未设循环的供水支管当长度L≥3~10m时，宜采用自动电伴热保温，电伴热保持管内水温按45℃设计（12YS3）。
- 试压：热水供应系统管道试压，当设计未注明时试验压力为顶点工作压力+0.1MPa，且不小于0.3MPa（12YS3）。
- 来源：GB 50015-2019 第6.8节；12YS3《热水供应系统说明》。

## 八、关键易错点提示

1. **半容积式/导流型容积式的有效容积系数不同**：半容积式及带罐内强制循环泵的水加热器η=1.0，计算容积不附加；导流型容积式η=0.8~0.9需附加（《集中热水供应系统设计探讨（一）》slide19）。
2. **循环泵要乘附加系数Kx=1.5~2.5**，不能直接用理论循环流量qx选泵；泵前回水总管必须设温度传感器控温（第6.7.10条）。
3. **太阳能热水≠太阳能光伏**：地方政府要求设置太阳能热水系统时，仅设太阳能光伏发电不能替代（《设计中常被误读的几个知识点》slide41）。
4. **半即热式对蒸汽热媒有硬性要求**：最低工作压力≥0.15MPa且供汽压力稳定，并需高精度温控，否则应选半容积式或容积式。
5. **医院水加热器不得少于2台**，且须采用无冷温水滞水区的设备；其余建筑检修工况下剩余能力≥设计小时供热量的60%。
6. **结垢修正**：热水管网水力计算时管道计算内径应扣减结垢缩小量（DN15~40扣2.5mm，50~100扣3.0mm，125~200扣4.0mm）。
7. **保温范围**：可能上冻的房间及入口附近管道应做保温；未设循环的长支管宜电伴热保持45℃。
