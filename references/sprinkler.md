# 自动喷水灭火系统设计计算参考

> 主要依据：GB 50084-2017《自动喷水灭火系统设计规范》、GB 55036-2022《消防设施通用规范》、CECS 263:2009《大空间智能型主动喷水灭火系统技术规程》、CECS 219:2007《简易自动喷水灭火系统应用技术规程》、12YS4《消防工程》（河南图集）。

## 1. 火灾危险等级划分

设置场所火灾危险等级划分为：**轻危险级、中危险级（Ⅰ级、Ⅱ级）、严重危险级（Ⅰ级、Ⅱ级）、仓库危险级（Ⅰ级、Ⅱ级、Ⅲ级）**。

来源：GB 50084-2017 第3.0.1条、附录A 表A

### 1.1 民用建筑和厂房

| 危险等级 | 设置场所举例 |
|---|---|
| 轻危险级 | 住宅建筑、幼儿园、老年人建筑、建筑高度24m及以下的旅馆、办公楼；仅在走道设置闭式系统的建筑等 |
| 中危险级 Ⅰ级 | ①高层民用建筑：旅馆、办公楼、综合楼、邮政楼、金融电信楼、指挥调度楼、广播电视楼（塔）等；②公共建筑（含单多高层）：医院、疗养院、图书馆（书库除外）、档案馆、展览馆（厅）、影剧院、音乐厅和礼堂（舞台除外）及其他娱乐场所；火车站、机场及码头的建筑；总建筑面积小于5000㎡的商场、总建筑面积小于1000㎡的地下商场等；③文化遗产建筑：木结构古建筑、国家文物保护单位等；④工业建筑：食品、家用电器、玻璃制品等工厂的备料与生产车间等；冷藏库、钢屋架等建筑构件 |
| 中危险级 Ⅱ级 | ①民用建筑：书库、舞台（葡萄架除外）、汽车停车场（库）、总建筑面积5000㎡及以上的商场、总建筑面积1000㎡及以上的地下商场、净空高度不超过8m、物品高度不超过3.5m的超级市场等；②工业建筑：棉毛麻丝及化纤的纺织、织物及制品、木材木器及胶合板、谷物加工、烟草及制品、食用酒（啤酒除外）、皮革及制品、造纸及纸制品、制药等工厂的备料与生产车间 |
| 严重危险级 Ⅰ级 | 印刷厂、酒精制品、可燃液体制品等工厂的备料与车间，净空高度不超过8m、物品高度超过3.5m的超级市场等 |
| 严重危险级 Ⅱ级 | 易燃液体喷雾操作区域、固体易燃物品、可燃的气溶胶制品、溶剂清洗、喷涂油漆、沥青制品等工厂的备料及生产车间、摄影棚、舞台葡萄架下部等 |

### 1.2 仓库危险级

| 危险等级 | 设置场所举例 |
|---|---|
| 仓库危险级 Ⅰ级 | 食品、烟酒、木箱、纸箱包装的不燃、难燃物品等 |

### 2.3 仓库危险级场所（表5.0.4-1~5.0.4-4）

仓库参数较多，设计时应按储存方式（堆垛托盘、单双多排货架、多排货架）和最大储物高度查 GB 50084-2017 表5.0.4-1~表5.0.4-4。要点：

- 仓库危险级Ⅰ级堆垛托盘：喷水强度8.0~14.0 L/(min·㎡)，作用面积160~200㎡，持续喷水时间1.0~1.5h
- 仓库危险级Ⅱ级堆垛托盘：喷水强度16.0~22.0 L/(min·㎡)，作用面积160~200㎡，持续喷水时间1.5~2.0h
- 货架储物高度大于7.5m时，应设置货架内置洒水喷头；顶板下洒水喷头的喷水强度不应低于18 L/(min·㎡)（Ⅰ级）或20 L/(min·㎡)（Ⅱ级），作用面积不应小于200㎡，持续喷水时间不应小于2h

> 来源：GB 50084-2017 表5.0.4-1~表5.0.4-4

### 2.4 持续喷水时间

- 除另有规定外，自动喷水灭火系统的持续喷水时间应按火灾延续时间不小于1h确定（GB 50084-2017 第5.0.16条）。
- GB 55036-2022 第4.0.4条（强条）：用于灭火时，应大于或等于1.0h；用于局部应用系统，应大于或等于0.5h；用于防护冷却时，应大于或等于设计所需防火冷却时间；用于防火分隔时，应大于或等于防火分隔处的设计耐火时间。

## 4. 水力计算

### 4.1 喷头流量公式（第9.1.1条）

```
q = K·√(10P)
```

- q：喷头流量（L/min）
- P：喷头工作压力（MPa）
- K：喷头流量系数（常用K=80、115、161、202、242、363等）

### 4.2 系统设计流量（第9.1.3条）

```
Q = (1/60) · Σ q_i    (i=1~n)
```

- Q：系统设计流量（L/s）
- q_i：最不利点作用面积内各喷头节点的流量（L/min）
- n：最不利点处作用面积内的洒水喷头数

### 4.3 作用面积法要点

- 水力计算选定的最不利点处作用面积宜为矩形，其长边应平行于配水支管，其长度不宜小于作用面积平方根的1.2倍（GB 50084-2017 第9.1.2条）。
- 系统设计流量应按最不利点处作用面积内喷头同时喷水的总流量确定。
- 最不利点处作用面积内任意4只喷头围合范围内的平均喷水强度，轻危险级、中危险级不应低于表5.0.1规定值的85%；严重危险级和仓库危险级不应低于表5.0.1和表5.0.4-1~表5.0.4-5的规定值（第9.1.5条）。

### 4.4 管道沿程损失（海澄-威廉公式，第9.2.2条）

```
i = 6.05 · (q_g^1.85 / (C_h^1.85 · d_j^4.87)) × 10^7
```

- i：管道单位长度的水头损失（kPa/m）
- d_j：管道计算内径（mm）
- q_g：管道设计流量（L/min）
- C_h：海澄-威廉系数（表9.2.2）

| 管道类型 | C_h 值 |
|---|---|
| 镀锌钢管 | 120 |
| 钢管、不锈钢管 | 120 |
| 涂覆钢管、氯化聚氯乙烯（PVC-C）管 | 150 |

> 来源：GB 50084-2017 表9.2.2

### 4.5 管道流速

管道内的水流速度宜采用经济流速，必要时可超过5m/s，但不应大于10m/s（GB 50084-2017 第9.2.1条）。

### 4.6 局部损失

管道的局部水头损失宜采用当量长度法计算，当量长度见 GB 50084-2017 附录C（表C 镀锌钢管件和阀门的当量长度表）。

### 4.7 水泵扬程或系统入口供水压力（第9.2.4条）

```
H = (1.20 ~ 1.40) · ΣP_p + P_0 + Z - h_c
```

- H：水泵扬程或系统入口的供水压力（MPa）
- ΣP_p：管道沿程和局部水头损失的累计值（MPa）；报警阀的局部水头损失应按产品样本或检测数据确定；无上述数据时，湿式报警阀取值0.04MPa、干式报警阀取值0.02MPa、预作用装置取值0.08MPa、雨淋报警阀取值0.07MPa、水流指示器取值0.02MPa
- P_0：最不利点处喷头的工作压力（MPa）
- Z：最不利点处喷头与消防水池最低水位或系统入口管水平中心线之间的高程差（MPa）；当系统入口管或消防水池最低水位高于最不利点处喷头时，Z应取负值
- h_c：从城市管网直接抽水时城市管网的最低水压（MPa）；当从消防水池吸水时，h_c取0

## 5. 报警阀组

### 5.1 系统选型（第4.2节）

| 系统类型 | 适用条件 |
|---|---|
| 湿式系统 | 环境温度不低于4℃且不高于70℃的场所 |
| 干式系统 | 环境温度低于4℃或高于70℃的场所 |
| 预作用系统 | ①系统处于准工作状态时严禁误喷的场所；②系统处于准工作状态时严禁管道充水的场所；③用于替代干式系统的场所 |
| 雨淋系统 | ①火灾的水平蔓延速度快、闭式洒水喷头的开放不能及时使喷水有效覆盖着火区域的场所；②设置场所的净空高度超过本规范第6.1.1条的规定，且必须迅速扑救初期火灾的场所；③火灾危险等级为严重危险级Ⅱ级的场所 |

### 5.2 每个报警阀组控制的喷头数（第6.2.3条）

- 湿式系统、预作用系统不宜超过 **800只**
- 干式系统不宜超过 **500只**

### 5.3 报警阀组其他要求

- 每个报警阀组供水的最高与最低位置洒水喷头，其高程差不宜大于50m（第6.2.4条）。
- 雨淋报警阀组的电磁阀，其入口应设过滤器（第6.2.5条）。
- 报警阀组宜设在安全及易于操作的地点，报警阀距地面的高度宜为1.2m（第6.2.6条）。
- 水力警铃的工作压力不应小于0.05MPa；与报警阀连接的管道，其管径应为20mm，总长不宜大于20m（第6.2.8条）。
- 串联接入湿式系统配水干管的其他自动喷水灭火系统，应分别设置独立的报警阀组，其控制的洒水喷头数计入湿式报警阀组控制的洒水喷头总数（第6.2.2条）。

## 6. 末端试水装置与试水阀

### 6.1 设置要求

- 每个报警阀组控制的最不利点洒水喷头处应设**末端试水装置**，其他防火分区、楼层均应设直径为 **25mm** 的试水阀（GB 50084-2017 第6.5.1条；GB 55036-2022 第4.0.6条强条）。
- 末端试水装置应由试水阀、压力表以及试水接头组成。试水接头出水口的流量系数，应等同于同楼层或防火分区内的最小流量系数洒水喷头。末端试水装置的出水，应采取孔口出流的方式排入排水管道，排水立管宜设伸顶通气管，且管径不应小于75mm（第6.5.2条）。
- 末端试水装置和试水阀应有标识，距地面的高度宜为1.5m，并应采取不被他用的措施（第6.5.3条）。

> 来源：GB 50084-2017 第6.5节；12YS4 页77

## 8. 简易自动喷水灭火系统

> 依据：CECS 219:2007。由响应时间指数 RTI≤50(m·s)^0.5 的闭式洒水喷头、供水管网和控制组件组成。

### 8.1 适用场所（第1.0.2条）

1. 建筑面积小于500㎡的小型歌舞娱乐放映游艺场所（歌舞厅、茶楼、保健中心、网吧、酒吧等）
2. 建筑面积小于1000㎡的商业设施
3. 建筑面积小于500㎡的生产作坊
4. 层数不大于三层的旅馆、招待所
5. 饮食建筑的主、副食热加工间
6. 居住场所

### 8.2 系统形式

- **简化型**：供水压力能满足喷头工作压力要求，且喷头总数不超过20只
- **通用型**：供水压力能满足喷头工作压力要求、人员集中，且喷头总数超过20只
- **增压型**：供水压力需通过增压来满足喷头工作压力要求、人员集中

### 8.3 设计基本参数（第3.3节）

| 项目 | 参数 |
|---|---|
| 喷水强度（小型旅馆、招待所、居住场所） | 不应小于3.0 L/(min·㎡) |
| 喷水强度（小型文化娱乐场所、中小型商店超市、中小型生产作坊） | 不应小于4.0 L/(min·㎡) |
| 通透型吊顶场所喷水强度 | 按规定值的1.3倍确定 |

## 9. 关键易错点

1. **喷水强度与作用面积别套错**：轻危险级4 L/(min·㎡)、中危Ⅰ级6、中危Ⅱ级8、严重Ⅰ级12、严重Ⅱ级16；作用面积轻/中危160㎡，严重危险级260㎡。住宅按轻危险级，不要按中危。
2. **每个报警阀组控制喷头数**：湿式/预作用≤800只，干式≤500只；每个阀组最高与最低喷头高程差≤50m。
3. **最不利点喷头工作压力**：不应低于0.05MPa（GB 55036-2022 第4.0.5条强条）。
4. **末端试水装置**：每个报警阀组最不利点处必须设末端试水装置（含压力表、试水阀、试水接头），其他防火分区/楼层设DN25试水阀；排水立管≥75mm。
5. **喷头间距与距墙**：标准覆盖面积喷头正方形布置边长，轻危4.4m、中危Ⅰ3.6m、中危Ⅱ3.4m、严重/仓库3.0m；距端墙最大距离2.2/1.8/1.7/1.5m，最小距墙0.1m。
6. **溅水盘与顶板距离**：标准覆盖面积/扩大覆盖面积/家用喷头（除吊顶型外）75~150mm；早期抑制快速响应直立型100~150mm、下垂型150~360mm。
7. **配水支管控制喷头数**：按表8.0.9，如DN50中危只能控制8只，轻危10只；不要凭经验放大。
8. **配水管入口压力**：轻/中危险级各配水管入口压力不宜大于0.40MPa，超了要减压。
9. **水泵扬程公式系数**：H=(1.20~1.40)ΣP_p + P_0 + Z - h_c；沿程局部损失累计值要乘1.2~1.4的安全系数。
10. **报警阀局部损失取值**：湿式0.04MPa、干式0.02MPa、预作用0.08MPa、雨淋0.07MPa、水流指示器0.02MPa。
11. **持续喷水时间**：一般场所不小于1h（强条）；局部应用系统不小于0.5h；仓库按表5.0.4取1.5~2h。
12. **建筑高度大于100m的公共建筑**：其高层主体内设置的自动喷水灭火系统应采用快速响应喷头（GB 55036-2022 第4.0.5条强条）。
13. **大空间智能炮**：净空高度>8m（仓库>12m）才用；标准型大空间智能灭火装置工作压力0.25MPa、保护半径6m；高空水炮工作压力0.6MPa、保护半径20m。
14. **简易自喷**：仅用于建筑面积<500㎡歌舞娱乐、<1000㎡商业、<500㎡作坊、≤3层旅馆等小型场所；最大净空≤6m；持续喷水≥30min。
