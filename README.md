# 建筑给排水工程设计与计算 Skill

一个面向 AI Agent 的建筑给排水工程设计与计算技能包，覆盖住宅、公建、工业建筑的室内给水、排水、消防、热水、雨水系统水力计算与计算书编制。

## 功能覆盖

- **生活给水**：用水量、设计秒流量、管径、分区、水泵扬程、叠压供水
- **生活排水**：排水当量、立管秒流量、排水能力、通气管、同层排水、特殊单立管
- **消防系统**：室内外消火栓水量、消防水池容积、消火栓系统压力、自动喷水灭火系统、灭火器配置
- **热水供应**：热水定额、耗热量、水加热器选型、太阳能集热面积、循环流量
- **屋面雨水**：暴雨强度公式、雨水量、87型/虹吸雨水斗、立管泄流量、海绵城市调蓄
- **地方规定**：郑州/河南特殊要求（市政水压、泵房设置、绿建要求、暴雨公式版本）
- **审查要点**：施工图审查高频问题、强条速查、常见错误对照

## 主要依据规范

- GB 50015-2019《建筑给水排水设计标准》
- GB 50016-2014（2018年版）《建筑设计防火规范》
- GB 50084-2017《自动喷水灭火系统设计规范》
- GB 50974-2014《消防给水及消火栓系统技术规范》
- GB 50140-2005《建筑灭火器配置设计规范》
- CJJ 142-2014《建筑屋面雨水排水系统技术规程》
- DBJ41/T 系列河南省地方标准
- 郑自然资文〔2023〕34号（郑州新版暴雨强度公式）
